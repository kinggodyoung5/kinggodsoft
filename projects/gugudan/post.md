# 개발 후기

## 만든 이유

구구단은 결국 순발력 싸움이라, 반복 연습을 게임처럼 만들면 애들이 더 열심히 한다. 시간제한을 두고 연속 정답 개수를 기록하게 해서, "몇 개까지 갈 수 있나" 하는 승부욕을 자극하는 방식으로 만들었다. 하나라도 틀리면 바로 끝나는 서든데스 구조라 은근히 긴장하면서 함.

## 어떻게 만들었나

- 빌드 도구 없이 순수 HTML/CSS/JS 한 파일로 구성. 서버 없이 그냥 열면 됨.
- 2단~9단 랜덤 출제, 문제당 제한시간 7초 → 연속 30개 넘어가면 5초로 단축.
- 디자인은 "수학 공책 채점" 컨셉으로 잡았다. 모눈종이 배경, 스프링 제본, 정답/오답을 빨간펜 동그라미·가위표로 표시, 연속 정답 마일스톤마다 "참 잘했어요" 도장이 화면에 쾅쾅 찍힘.
- 사운드는 전부 Web Audio API로 실시간 합성 (효과음 파일 없음): 정답 종소리, 도장 찍는 소리, 게임 끝날 때 박수소리, 배경엔 아주 작은 볼륨의 8비트풍 루프. 좌상단에 음소거 토글 있음.
- 업적(뱃지) 시스템: 누적 정답 수·연속기록·플레이 횟수 기준으로 9종 도장을 모으는 "도장첩" 화면 추가.
- 한 기기를 여러 명이 같이 쓰는 교실 환경을 고려해서, 시작하면 "출석부" 화면에서 이름을 고르고 들어가는 구조로 만들었다. 이름별로 기록/업적이 localStorage에 분리 저장되고, 마지막에 쓰던 사람으로 자동 복귀함. 진짜 로그인은 아니고 그냥 이름으로 나눠 저장하는 수준이라 보안은 없음.

## 배운 점 / 다음에 할 일

- 특정 단(예: 7단)만 집중적으로 틀리는 학생을 위한 "약점 단 집중 모드" 를 추가하면 학습 효과가 더 클 것 같다.
- 지금은 기기 로컬 저장이라 다른 기기로 옮기면 기록이 사라짐. 반 전체 기록을 한눈에 보고 싶다면 나중에 내보내기/불러오기 정도는 붙일 만함.
