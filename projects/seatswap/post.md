# 개발 후기

## 만든 이유

학급의 자리 배치 상황을 반영하며 이에 맞게 랜덤 배치 및 교사가 원하는 배치를 할 수 있는 프로그램.
핵심은 학생은 랜덤 배치라고 알고 있다는 것. 

## 어떻게 만들었나

- **교사용 / 학생용 두 화면**: 교사용에서 학생 명단·좌석 구조(분단 개수, 분단별 줄 수, 짝 구조/혼자 앉기)를 설정하고 자리를 배치하면, 학생용 화면에는 추첨 연출(슬롯머신처럼 이름이 돌아가는 애니메이션)과 함께 그대로 결과가 나옴. 

- **짝 유형**: 남녀짝 / 동성짝 / 랜덤짝을 고를 수 있고, 인원이 딱 안 맞아 남는 학생은 성별과 무관하게 자동으로 짝이 됨.

- **반복 방지 로직**: 랜덤 배치 결과를 "기록"해두면, 다음 배치 때 ① 직전에 맨 뒷줄이었던 학생을 앞줄로 우선 배정하고 ② 직전에 짝이었던 학생끼리는 다시 짝이 되지 않도록 피함. 굳이 필요없다면 기록하지 않고 그냥 하면 됨.

- **교사 개입**: 특정 학생을 특정 자리에 고정하거나, 특정 자리를 아예 빈자리로 고정하는 것도 가능해서 순수 랜덤과 교사 지정을 섞어 쓸 수 있음. 

- **저장 방식**: 서버 없이 브라우저에 자동 저장되고, JSON 파일로 내보내기/불러오기를 지원해서 다른 컴퓨터로 옮기거나 학기 초 백업용으로 쓸 수 있음. 인쇄용 스타일도 별도로 마련해 좌석표 출력 가능.

## 배운 점 / 다음에 할 일

현재 나의 학급에서는 잘 작동하기 때문에 많은 변수를 확인하지 못함. 더 많은 테스트와 변수(오류) 체크 및 사용자 편의성 개선 필요.
